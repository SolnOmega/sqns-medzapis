# SQNS · Помощник медзаписи

Панель для SQNS: шаблоны дневника приёма и протокола ЕГИСЗ (СЭМД 227) с предзаполнением по услугам и зубам визита.

## Файлы

| Файл | Что внутри | Когда править |
|---|---|---|
| `sqns-medzapis.user.js` | Заголовок для Tampermonkey: версия и ссылки на два файла ниже | При каждом обновлении поднять `@version` и `?v=` |
| `templates.js` | Должности, правила «услуга → параметр», шаблоны и их тексты | Новые шаблоны, формулировки, материалы |
| `engine.js` | Панель, чтение и запись данных SQNS | Только при изменении логики |

## Установка на ПК

1. В Chrome: `chrome://extensions` → Tampermonkey → «Подробнее» → включить «Разрешить пользовательские скрипты».
2. Открыть raw-ссылку на `sqns-medzapis.user.js` → Tampermonkey предложит установить → «Установить».
3. Старую вставленную вручную версию в Tampermonkey отключить или удалить.

## Обновление

Tampermonkey сам проверяет обновления. Чтобы получить их сразу: значок Tampermonkey → «Панель управления» → «Проверить обновления пользовательских скриптов».

Данных пациентов в репозитории нет и быть не должно.
