# SQNS · Помощник медзаписи

Панель для SQNS: шаблоны дневника приёма и протокола ЕГИСЗ (СЭМД 227) с предзаполнением по услугам и зубам визита, а также помощник быстрого добавления услуг в визит (вкладка «Услуги»).

## Файлы

| Файл | Что внутри | Когда править |
|---|---|---|
| `sqns-medzapis.user.js` | Заголовок для Tampermonkey: версия и ссылки на файлы ниже | При каждом обновлении поднять `@version` и `?v=` |
| `templates.js` | Должности, правила «услуга → параметр», шаблоны дневника и их тексты | Новые шаблоны, формулировки, материалы |
| `services.js` | Сценарии вкладки «Услуги»: какие услуги (по id прайса SQNS) и с какими опциями | Новые сценарии, умолчания |
| `svc-engine.js` | Вкладка «Услуги»: интерфейс, корзина, добавление строк в визит | Только при изменении логики |
| `engine.js` | Панель, чтение и запись данных SQNS | Только при изменении логики |

## Установка на ПК

1. В Chrome: `chrome://extensions` → Tampermonkey → «Подробнее» → включить «Разрешить пользовательские скрипты».
2. Открыть raw-ссылку на `sqns-medzapis.user.js` → Tampermonkey предложит установить → «Установить».
3. Старую вставленную вручную версию в Tampermonkey отключить или удалить.

## Обновление

Tampermonkey сам проверяет обновления. Чтобы получить их сразу: значок Tampermonkey → «Панель управления» → «Проверить обновления пользовательских скриптов».

Данных пациентов в репозитории нет и быть не должно.
